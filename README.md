# Student Management System using C++

I created this project using C++ to practise my programming skills and understand how a basic student management system works.

The program runs in the terminal and allows users to manage student records.

## What can it do?

- Add a new student
- Display all student records
- Search for a student using their ID
- Update student details
- Delete a student record
- Calculate grades based on marks
- Save student records in a file so they are available the next time the program runs

## Technologies I used

- C++
- Classes and Objects
- Vectors
- File Handling

## How to run the project

You need a C++ compiler such as GCC installed on your computer.

Compile the program:

```bash
g++ main.cpp -o main
```

Run on Windows:

```powershell
.\main.exe
```

## What I learned

While making this project, I learned how to use classes, objects, vectors, functions, and file handling. I also got some practice with searching, updating, and deleting records in C++.
